How does this work?
  1. GitHub stores a fingerprint for every file on the official release pages. Craft Watch copies those fingerprints from the official repositories.
  2. Your file’s fingerprint is calculated in this page, on your computer. If even one byte of the file was changed, the fingerprint is completely different.
  3. A match means your file is byte-for-byte a file the team published. No match means it isn’t one of the official files we know.
  4. The link checker only reads public GitHub facts. It doesn’t download the file.

Signals, not a guarantee. A match tells you the file is the official one, not that the app has no bugs.
