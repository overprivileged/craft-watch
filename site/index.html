    What do the symbols actually mean?

    · Commit

    A saved change to source code. This map records commits on the default branch. A commit does not by itself mean a new downloadable version exists.

    ○ Pull request created

    Someone proposes a change for review. The arc starts when the PR is created and spans the time until it is merged or closed. An amber dashed arc is still in progress at the displayed time.

    ◆ Merged / × closed

    Merged means the proposed change was accepted into its target branch. Closed means it ended without merging. A merge can later be included in a release; the time order alone does not prove it shipped.

    ★ Release published

    A named version was published on GitHub, sometimes as a prerelease. Open the star to see the notes and available downloads. Release, commit, and PR counts measure different things and should not be added together.

    Use “Show on map” to switch layers independently and “Display limits” to set per-app caps or choose Unlimited. Commit and release caps keep the newest events reached so far; arc caps keep the PRs with the most recent activity. Capped items can disappear when newer items take their place. Unlimited removes that replacement behavior. The “Show version above every release symbol” checkbox updates immediately: checked shows every version label, unchecked hides them all. Labels may overlap when stars are close together. Amber circles and cyan squares represent recorded PRs and issues still open at the displayed time; they disappear when merged or closed. The PR created layer instead shows creation events within the range and keeps them after merging or closing. Connector lines require visible PR created and PR merged endpoints. Historical states are approximate because reopen transitions and some older records are not collected.

    Arc height is only for legibility. Its horizontal span shows elapsed time. Latest shows your chosen range ending at the latest data update. Both Latest and replays use an evenly spaced time scale. Choosing a range returns to Latest. Open PR totals are separate from bug reports (GitHub issues).

    Historical open PR totals are estimates reconstructed from the latest count and recorded openings, merges, and closures. Reopen transitions are not collected. Missing records and delayed app updates can affect these estimates.
